# Factores-de-riesgo-protecci-n-e-ndice-de-probabilidad-de-reclutamiento-de-ni-os-ni-as-y-adolescentes
Repositorio asociado a la tesina Factores de riesgo, protección e índice de probabilidad de reclutamiento de niñas, niños y adolescentes: una propuesta de modelación matemática para el caso mexicano. Este proyecto contiene el código utilizado para implementar y analizar un índice de probabilidad de reclutamiento adolescente basado en factores de riesgo y protección ponderados mediante el Proceso Analítico Jerárquico (AHP). El repositorio incluye herramientas para calcular vectores de pesos, evaluar consistencia en matrices de comparación por pares, construir perfiles binarios de vulnerabilidad, estimar el índice individualizado y explorar escenarios de acumulación de riesgos, efectos protectores y sensibilidad del parámetro α. Su propósito es acompañar la propuesta matemática desarrollada en la tesina y facilitar la reproducibilidad, revisión y futura ampliación del modelo.
