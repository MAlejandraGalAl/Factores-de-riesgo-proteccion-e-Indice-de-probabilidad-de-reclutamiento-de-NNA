# Factores-de-riesgo-protecci-n-e-ndice-de-probabilidad-de-reclutamiento-de-ni-os-ni-as-y-adolescentes
Código asociado a una propuesta de modelación matemática para estimar un índice de vulnerabilidad relativa al reclutamiento de niñas, niños y adolescentes por el crimen organizado en México, integrando factores de riesgo y protección ponderados mediante AHP.
